# BuyList 🛒

App Android de lista de compras — desenvolvido por Roger.

## Como gerar o APK (sem instalar nada no PC)

### 1. Crie uma conta no GitHub
Acesse https://github.com e crie uma conta gratuita.

### 2. Crie um repositório novo
- Clique em **New repository**
- Nome: `BuyList`
- Deixe **Public**
- Clique em **Create repository**

### 3. Faça upload dos arquivos
- Clique em **uploading an existing file**
- Arraste a pasta completa do projeto para o GitHub
- Clique em **Commit changes**

### 4. Aguarde o build automático
- Vá na aba **Actions** do repositório
- O build inicia automaticamente (leva ~3 minutos)
- Quando terminar, clique no build e baixe o arquivo **BuyList-APK**

### 5. Instale no celular
- Extraia o `.apk` do arquivo ZIP baixado
- Transfira para o celular e instale
- Se necessário, ative **Instalar de fontes desconhecidas** nas configurações
